# BodycamAutoRP

Small Python automation script to farm Bodycam RP by repeating a fixed in-game loop using keyboard and mouse input.

## Requirements
- Python 3
- `pydirectinput`

```bash
pip install pydirectinput
```

## Usage
```bash
python main.py
```

The script waits a few seconds, starts the loop, and repeats until stopped. Make sure the game window is focused and the in-game menu is 2D. Script positions are for 1440p display.
